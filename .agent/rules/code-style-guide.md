このプロジェクトでプログラムを実行する際には，source persona_steering/bin/activateで仮想環境を立ち上げてからプログラムを実行してください．

実験を行う場合は，logフォルダにログが残るようにして，実験を実行してください．

実験を行った後、または新たな結果が得られた場合は、各性格特性ごとのヒートマップおよび全性格特性のサマリーヒートマップ（例：scripts/04_dyn_layer/67_plot_dyn_layer_heatmaps.py などを使用）を最優先で作成してください。

モデルのロード、大量のデータに対する隠れ状態の抽出、スイープ実行などの高負荷な計算処理は、ログインノード上で直接実行（またはバックグラウンドで直接実行）しないでください。サーバーの過負荷を防ぎSSH接続等の安定性を維持するため、重い処理は必ずSLURM（sbatch）を介して実行ノード（GPUノード等）にジョブとして投入して実行してください。
